## 1.   Why was a Queue appropriate for the waiting room? 
            A queue is appropriate for the waiting room because it follows the FIFO (First In, First Out) principle, which ensures that patients are served in the order they arrive. This is important in a medical setting to maintain fairness and efficiency, as it allows for a systematic approach to patient care. My queue also uses a triage level system to prioritize patients based on the severity of their condition, ensuring that those in critical need are attended to first while still maintaining the order of arrival for patients with similar triage levels.

## 2.   Explain FIFO principle
            The FIFO principle is the rule that the first element added to a queue will be the first one to be removed. In other words, the first patient to arrive in the waiting room will be the first to be served, and the last patient to arrive will be the last to be served.

## 3.   Explain what could happen if a stack was used instead of a queue in Part 1.  
            If a stack was used instead of a queue, the latest patient to arrive would be the first to be served.
